# Contributing

- Keep runtime code compatible with Python 3.9 and free of third-party dependencies.
- Mark all example facts as synthetic.
- Add fixed-seed tests for stochastic behavior.
- Explain new risk factors, their units, and dependence assumptions.
- Update schema documentation and `CHANGELOG.md` for artifact changes.
- Run `make test` before opening a pull request.

Never contribute confidential positions, live counterparty data, credentials, or unlicensed market data.
